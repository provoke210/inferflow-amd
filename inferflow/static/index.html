02 / RECORDED AMD EXPERIMENT

Earlier answers, later summaries

One sequential cold-cache comparison on DeepSeek-V4-Flash. Both arms used the same six synthetic requests, 20 RPM and a concurrency cap of two. These are saved results, not new calls from this page.

Only 3 requests per class. No statistical significance or production p95 claim. Background median latency increased while interaction latency fell.

Protocol, failures and quota

Three background summaries arrived at 0, 0.02 and 0.04 seconds. Three questions arrived at 0.2, 0.4 and 0.6 seconds, with one exact repeat. Each arm started with an empty cache after at least 61 seconds since the last provider call.

The first attempt encountered HTTP 502 errors. Its complete record remains available. After recovery, both cold arms ran again with the same revised prompt. The real warm-cache pair was omitted to preserve the original 30-call budget. In total, the study used 27 new upstream attempts, including failed calls and quota queries. No 429 occurred.

Priority scheduling and caching changed together. Provider variation and different output lengths limit causal claims. This is application-layer request scheduling, not GPU continuous batching.
